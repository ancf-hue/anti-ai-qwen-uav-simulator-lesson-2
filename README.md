# 🛸 Анти ИИ Qwen БПЛА Тренажёр — Урок 2: Навигация

**Бесплатный социальный офлайн-3D-тренажёр для подготовки операторов БПЛА**  
*Проект образовательной платформы [Anti-AI Qwen Academy](https://ancf-hue.github.io/)*

---

## 📖 О проекте

Тренажёр предназначен для базовой отработки навыков пилотирования беспилотных летательных аппаратов (БПЛА) в закрытом полигоне. Оператор с позывным **«Автомобиль»** должен провести квадрокоптер через трассу с препятствиями, последовательно пролетая через 5 контрольных арок (чекпоинтов).

### 🎯 Учебные цели Урока 2:
- Освоение пространственного ориентирования на закрытом полигоне
- Отработка мышечной памяти и плавного управления
- Контроль габаритов и безопасное пилотирование
- Работа с телеметрией (АКБ, время, скорость)

---

## ✨ Возможности

| Функция | Описание |
|---|---|
| 🛸 **3D FPV-дрон** | Детализированная модель квадрокоптера с карбоновой рамой, 4 моторами, FPV-камерой |
| 🔄 **Реалистичное управление** | Поворот работает даже на месте (как у настоящего дрона) |
| 🚧 **Препятствия** | 10 препятствий на трассе: колонны и стены-перегородки |
| 🏁 **Чекпоинты** | 5 контрольных арок с анимацией и звуком |
| 🔋 **Телеметрия** | Расход АКБ зависит от скорости, таймер миссии (90 сек) |
| 💨 **Дымовой шлейф** | Неоновый след за дроном при движении |
| 🎵 **Звуковое сопровождение** | Файл `avtomobil-theme.mp3` + синтезаторные эффекты |
| 💥 **Физика столкновений** | Отскок от препятствий с эффектом аварии |
| 📱 **Адаптивность** | Работает на ПК и мобильных устройствах |
| 🌐 **Офлайн-режим** | Не требует интернета (кроме первой загрузки Three.js) |

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| `W` / `↑` / `Ц` | Газ (вперёд) |
| `S` / `↓` / `Ы` | Тормоз / Задний ход |
| `A` / `←` / `Ф` | Поворот влево (работает на месте!) |
| `D` / `→` / `В` | Поворот вправо (работает на месте!) |

🛠 Технологии
HTML5 / CSS3 — интерфейс и стили
JavaScript (ES6+) — логика симулятора
Three.js r128 — 3D-рендеринг
Web Audio API — синтезаторные звуки
WebGL — аппаратное ускорение графики


🎓 Образовательная ценность
Проект разработан в рамках программы Anti-AI Qwen Academy и является частью курса подготовки операторов БПЛА. Урок 2 «Навигация» — это обязательный «песочный» уровень перед допуском к реальным задачам.
Связь с Уроком 1:
Урок 1: Базовое управление, знакомство с интерфейсом
Урок 2: Навигация через препятствия, работа с телеметрией
Урок 3 (в разработке): Реальные сценарии, динамические объекты
