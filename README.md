# 🚁 БПЛА Тренажёр: Оператор «Автомобиль» (Урок 2: Навигация)

Интерактивный 3D-тренажёр, разработанный для обучения и отработки навыков операторов беспилотных летательных аппаратов (БПЛА). Данный модуль фокусируется на **навыках навигации**, управлении скоростью и точном прохождении контрольных точек (чекпоинтов) в условиях ограниченного времени и наличия динамических препятствий.

## ✨ Ключевые особенности

* 🎮 **Три уровня сложности:** 
  * 🟢 *Лёгкий:* 3 чекпоинта, 120 сек, минимум препятствий.
  * 🟡 *Средний:* 5 чекпоинтов, 90 сек, стандартная трасса.
  * 🔴 *Сложный:* 7 чекпоинтов, 60 сек, высокая плотность препятствий и скорость.
* 🌍 **3D-графика:** Реализована на библиотеке **Three.js** с динамическим освещением, тенями, свечением (bloom-эффекты) и системой частиц (дым при движении).
* ⚙️ **Физика движения:** Инерция, плавный разгон, торможение, дрифт и реалистичная обработка столкновений с отскоком от стен и объектов.
* 🔊 **Продвинутая аудиосистема:** Фоновая музыка и процедурно генерируемые звуковые эффекты через **Web Audio API** (звук двигателя, зависящий от скорости, удары, сбор чекпоинтов).
* 📱 **Адаптивный HUD-интерфейс:** Панель со спидометром, таймером обратного отсчёта, зарядом АКБ и счётчиком чекпоинтов. Корректно отображается на десктопах и мобильных устройствах.
* 🛡️ **Умная оптимизация:** Автоматическое определение слабых устройств (Low-End) для снижения нагрузки на GPU (отключение сглаживания, уменьшение количества частиц).

## 🛠️ Технологический стек

* **Frontend:** HTML5, CSS3 (CSS Variables, Animations, Backdrop Filter)
* **Logic:** JavaScript (ES6+)
* **3D Engine:** [Three.js](https://threejs.org/) (r128)
* **Audio:** Web Audio API (Oscillators, GainNodes)

## 🎮 Управление

| Клавиша | Действие |
| :---: | :--- |
| `W` или `↑` | Газ (движение вперёд) |
| `S` или `↓` | Тормоз / Задний ход |
| `A` или `←` | Поворот влево |
| `D` или `→` | Поворот вправо |
| `R` или кнопка на экране | Перезапуск упражнения |
